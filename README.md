# CloudBaseVario

CloudBaseVarioは、ハンググライダーおよびパラグライダー向けの自作バリオメーターを開発するプロジェクトです。


## 特徴
- 高分解能気圧センサーとIMUを融合した昇降率推定
- ピエゾドライバと大型スピーカーを使った~~大きな~~そんなに大きくなかったバリオ音
- Bluetooth(BLE)経由でのXCTrack連携
- USB CDC/MSCによるモニター、設定、およびファームウェア更新


> [!WARNING]
> 本プロジェクトは開発中の実験用機器です。動作・精度・安全性を保証しません。本機器に依存せずにフライトできる環境で使用してください。


## 利用できる機能

- 高度と昇降率を測定し、上昇・下降をバリオ音で知らせます。
- 機体の傾きを測定し、昇降率の表示を安定させます。
- スイッチ操作で電源を入切し、LEDで動作状態を確認できます。
- バッテリー残量を確認できます。
- BLEでXCTrackなどの対応アプリへ飛行データを送信できます。
- USB接続で動作状態を確認し、設定を保存・変更できます。
- USBストレージへ更新ファイルをコピーして、ファームウェアを更新できます。更新に失敗した場合は以前のファームウェアへ戻ります。


## 設定の変更

USBストレージのルートにある `setting.json` で、機体や好みに合わせて動作を調整できます。設定ファイルはファームウェアを更新しても保持されます。

- 高度を補正するための基準気圧と、未使用時の自動電源オフを設定できます。
- 昇降率の算出方法を、姿勢センサーを併用する通常モード、または気圧センサーだけを使うモードから選べます。
- BLEで送る電池残量の表示方法、通信の強さ、送信頻度を調整できます。
- 上昇・下降を知らせ始める昇降率、音程、テンポ、予測音などを、飛行スタイルごとに最大5組登録できます。SW3で使う組を選択できます。
- 音量はSW1、下降音のオン・オフはSW2で操作します。これらは `setting.json` には含まれません。

PCで編集する場合は、まず `setting.json` をバックアップし、UTF-8対応のテキストエディタで編集して保存します。OSの「安全な取り外し」を実行してから本体を再起動すると、新しい設定が読み込まれます。不正な内容のファイルは使われず、すべての設定が初期値で起動するため、編集後はUSB接続で設定を確認してください。ファイルがない場合は、初期値のファイルが自動的に作成されます。

設定項目、選択肢、入力できる範囲は、[`setting.json` 設定ファイル説明書](DOC/setting_json.md)および[初期設定例](DOC/default_setting.json)を参照してください。


## ファームウェア更新

`UPDATE.BIN` を使用します。ファイル名を変更したり、展開したりしないでください。

1. USBのMSCドライブ直下へ `UPDATE.BIN`をコピーします。
2. OSの「安全な取り外し」を実行します。
3. USB外部給電を接続した状態、または有効な電池電圧が3.4 Vを超える状態で本体を再起動します。

更新中はMSCドライブが一時的に表示されなくなります。新しいファームウェアで10秒間正常に起動すると更新完了となり、再表示されたドライブの `UPDATE_RESULT.TXT`で `state=CONFIRMED`、手動管理の`version`、7桁Git `hash`を確認できます。`setting.json`は更新時もそのまま保持されます。

更新できなかった場合も、次のように元のファームウェアで動作を継続または復旧します。詳しい理由は `UPDATE_RESULT.TXT`で確認できます。

- USB外部給電がなく、電池電圧が3.4 V以下または取得できない場合: 更新を延期し、`UPDATE.BIN`を残します。USBを接続するか十分に充電して再起動してください。
- `UPDATE_RESULT.TXT`が`REJECTED`の場合: 配布元から改めて取得した署名済み `UPDATE.BIN`をコピーしてください。
- 新しいファームウェアが確認中にresetまたはcrashした場合: 自動的に以前のファームウェアへ戻ります。解決しない場合は配布元へ連絡してください。
