= バリオ音仕様
:toc:
:toclevels: 3
:sectnums:
:revdate: 2026-06-19

== 目的

本プロジェクトにおけるバリオメータの音に関する仕様を定義する。 +
本書では、ソフトウェア構造、タスク構成、PWM 制御、センサ読み取り方式などの実装仕様は対象外とする。

== 利用者価値

操縦者は画面やシリアル出力を見なくても、音だけで上昇、沈下、無音域を直感的に区別できること。
音は飛行判断を助けるための補助情報であり、不要な鳴動や細かな揺らぎで操縦者の集中を妨げてはならない。

== 用語

[cols="1,3",options="header"]
|===
|用語 |意味

|上昇率
|機体の鉛直方向の速度。正の値は上昇、負の値は沈下を表す。

|リフト音
|上昇気流または上昇傾向を知らせる断続音。

|シンク音
|強い沈下を知らせる連続音。

|無音域
|明確な上昇でも強い沈下でもない状態。通常は無音とする。

|予測ブザー
|弱い上昇またはゼロ付近の状態を知らせる任意の補助音。
|===

== 基本要求

[cols="1,4",options="header"]
|===
|ID |要求

|VA-REQ-001
|バリオ音は、上昇、沈下、無音域を聞き分けられる音として提示すること。

|VA-REQ-002
|上昇傾向が強くなるほど、リフト音は高い音程かつ短い間隔の断続音として知覚できること。

|VA-REQ-003
|沈下傾向が強くなるほど、シンク音は低い音程として知覚できること。

|VA-REQ-004
|明確な上昇でも強い沈下でもない状態では、通常は無音であること。

|VA-REQ-005
|センサ値が無効、古い、または音が無効化されている状態では、音を鳴らさないこと。

|VA-REQ-006
|上昇率がしきい値付近で揺らぐ場合でも、音のオン/オフが細かく震えないこと。

|VA-REQ-007
|音の変化は操縦者が遅れを感じにくい応答性を持つこと。

|VA-REQ-008
|音量感は機体、ブザー、利用環境に合わせて調整できること。
|===

== 体験モード

=== リフト音

リフト音は、操縦者に「上昇に入った」「上昇が強まった」ことを知らせる。

[cols="1,4",options="header"]
|===
|ID |要求

|VA-LIFT-001
|上昇率がリフト開始しきい値を超えた場合、リフト音を開始すること。

|VA-LIFT-002
|リフト音は断続音とし、連続音のシンク音と容易に区別できること。

|VA-LIFT-003
|上昇率が強いほど、リフト音の音程を高くすること。

|VA-LIFT-004
|上昇率が強いほど、リフト音の鳴動時間と休止時間を短くし、より速いテンポとして知覚できること。

|VA-LIFT-005
|リフト終了しきい値を下回った場合でも、音は急に乱れず、自然な区切りで無音へ戻ること。
|===

.標準的なリフト音イメージ
[cols="1,1,2",options="header"]
|===
|上昇率 |鳴動/休止の目安 |ユーザーが受け取る印象

|+0.2 m/s
|約 480 ms / 約 480 ms
|弱い上昇。ゆっくりした断続音。

|+1.0 m/s
|約 220 ms / 約 220 ms
|実用的な上昇。明確にテンポが上がる。

|+2.5 m/s
|約 100 ms / 約 100 ms
|強い上昇。素早い断続音。

|+5.0 m/s 以上
|約 70 ms / 約 70 ms
|非常に強い上昇。高密度の断続音。
|===

=== シンク音

シンク音は、操縦者に「強い沈下に入った」ことを知らせる警告寄りの音とする。

[cols="1,4",options="header"]
|===
|ID |要求

|VA-SINK-001
|上昇率が沈下開始しきい値を下回った場合、シンク音を開始すること。

|VA-SINK-002
|シンク音は連続音とし、リフト音の断続音と容易に区別できること。

|VA-SINK-003
|沈下が強いほど、シンク音の音程を低くすること。

|VA-SINK-004
|極端な沈下でも、聞き取りにくいほど低い音程にはしないこと。

|VA-SINK-005
|沈下が弱まり沈下解除しきい値を上回った場合、シンク音を停止すること。
|===

=== 無音域

無音域は、操縦者に「積極的に反応すべき上昇または沈下ではない」ことを知らせる。

[cols="1,4",options="header"]
|===
|ID |要求

|VA-SILENT-001
|上昇率がリフト開始しきい値以下かつ沈下開始しきい値以上の場合、原則として無音とすること。

|VA-SILENT-002
|無音域では、不要なビープ音によって操縦者の注意を奪わないこと。

|VA-SILENT-003
|無音域からリフト音またはシンク音に移るときは、状態変化が分かる程度に速く反応すること。
|===

=== 予測ブザー

予測ブザーは任意機能とする。
有効化された場合のみ、ゼロ付近または弱い上昇域を知らせる補助音として使う。

[cols="1,4",options="header"]
|===
|ID |要求

|VA-BUZZ-001
|予測ブザーは標準では無効とし、必要なユーザーだけが有効化できること。

|VA-BUZZ-002
|有効時は、沈下警告や明確なリフト音とは異なる短周期の音として知覚できること。

|VA-BUZZ-003
|明確なリフトまたは強い沈下が発生した場合、予測ブザーよりリフト音またはシンク音を優先すること。

|VA-BUZZ-004
|予測ブザーは、無音域を完全に置き換えるものではなく、利用者が好みに応じて選択できる補助体験とすること。
|===

== 標準設定

以下は現行の標準体験を表す要求値である。
機体、ブザー、利用者の好みに合わせて調整可能であること。

[cols="2,1,3",options="header"]
|===
|項目 |標準値 |体験上の意味

|音の有効状態
|有効
|起動後、利用可能な上昇率が得られれば音で状態を知らせる。

|音量感
|50 %
|過度に大きすぎない標準的な鳴動。

|音の更新周期
|約 10 ms
|上昇率変化に対して遅れを感じにくい追従性。

|古いデータの無音化
|約 500 ms
|センサ更新が止まった場合に鳴り続けない。

|リフト開始
|+0.1 m/s 超
|ごく弱い上昇からリフト音を開始する。

|リフト終了
|+0.05 m/s 未満
|しきい値付近の細かな揺らぎで鳴動が震えないようにする。

|沈下開始
|-1.0 m/s 未満
|操縦者が注意すべき沈下で連続音を開始する。

|沈下終了
|-0.8 m/s 超
|シンク音のオン/オフにヒステリシスを持たせる。

|シンク音
|有効
|強い沈下を連続音で知らせる。不要な場合は個別に無効化できる。

|シンク音の最低音程
|130 Hz
|極端な沈下でも聞き取り可能な低音に留める。

|状態の最小保持
|約 60 ms
|短時間のノイズで音状態が頻繁に切り替わらないようにする。

|予測ブザー
|無効
|標準では静かな無音域を優先する。
|===

NOTE: リフト音の基準音程は、現行コード上で起動時の初期値とリセット時の既定値が一致していない。
ユーザー体験仕様としては、標準音程を単一の値に統一し、リセット後も同じ音の印象に戻ることを要求する。

== 調整要求

[cols="1,4",options="header"]
|===
|ID |要求

|VA-TUNE-001
|利用者は、音の有効/無効を切り替えられること。

|VA-TUNE-002
|利用者は、リフト開始/終了しきい値を調整できること。

|VA-TUNE-003
|利用者は、沈下開始/終了しきい値を調整できること。

|VA-TUNE-004
|利用者は、リフト音とシンク音の音程特性を調整できること。

|VA-TUNE-005
|利用者は、リフト音のテンポを全体的に速くまたは遅く調整できること。

|VA-TUNE-006
|利用者は、予測ブザーの有効/無効、音程、鳴動時間、休止時間を調整できること。

|VA-TUNE-007
|利用者は、シンク音の有効/無効をリフト音や予測ブザーとは独立して切り替えられること。
|===

== 安全性と快適性

[cols="1,4",options="header"]
|===
|ID |要求

|VA-COMFORT-001
|無効な測定値、ウォームアップ中の値、または古い値に基づいて音を鳴らさないこと。

|VA-COMFORT-002
|リフト音、シンク音、予測ブザーは、飛行中に混同しにくい音型とすること。

|VA-COMFORT-003
|しきい値付近の短時間の揺らぎでは、音の状態が過剰に切り替わらないこと。

|VA-COMFORT-004
|音量感は、静かな室内確認と屋外利用の両方に合わせられること。

|VA-COMFORT-005
|シンク音は警告性を持つが、長時間聞いても不快すぎない音程範囲に収めること。
|===

== 受け入れ基準

[cols="1,4",options="header"]
|===
|ID |確認内容

|VA-AC-001
|上昇率を +0.1 m/s より大きくすると、断続的なリフト音が聞こえること。

|VA-AC-002
|上昇率を +0.2 m/s、+1.0 m/s、+2.5 m/s、+5.0 m/s と上げると、音程とテンポが段階的に強い上昇として知覚できること。

|VA-AC-003
|上昇率を +0.05 m/s 未満へ下げると、リフト音が自然な区切りで停止すること。

|VA-AC-004
|上昇率を -1.0 m/s より小さくすると、連続したシンク音が聞こえること。

|VA-AC-005
|上昇率を -1.0 m/s、-2.0 m/s、-3.0 m/s と下げると、シンク音がより低く知覚できること。

|VA-AC-006
|上昇率を -0.8 m/s より大きく戻すと、シンク音が停止すること。

|VA-AC-007
|音を無効化した場合、上昇率にかかわらず音が鳴らないこと。

|VA-AC-008
|測定値が無効または古い状態では、音が鳴らないこと。

|VA-AC-009
|予測ブザーを有効化した場合、ゼロ付近の補助音が聞こえ、明確なリフトまたは沈下ではそれぞれの音に切り替わること。

|VA-AC-010
|シンク音を無効化した場合、沈下開始しきい値を下回ってもシンク音が鳴らず、再度有効化すると通常のシンク音動作に戻ること。
|===

== 未決事項

* リフト音の標準基準音程を、起動時とリセット時で同じ値に統一する。
* 実機ブザーと筐体に合わせて、標準音量感と音程範囲を聴感評価で確定する。
* 予測ブザーを製品上の標準体験に含めるか、上級者向け設定として扱うかを決める。
