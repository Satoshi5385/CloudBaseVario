## 1. 目的

本書は、CloudBaseVarioが操縦者へ提示するバリオ音の仕様を定義する。
操縦者が画面を見なくても、上昇、強い沈下、通常の無音域を直感的に区別できることを目的とする。

本書は、[`vario_audio_requirements.adoc`](./vario_audio_requirements.adoc) の利用者要求を基準とし、XC Tracer Mini VおよびMaxx IIIの音設定に関する調査結果を、CloudBaseVarioへ適用できる形に整理して統合したものである。

本書の「要求」は必須、「推奨」は可能な限り満たす事項、「任意」は利用者または製品構成により選択できる事項を表す。

## 2. 文書の位置付け

バリオ音の動作、標準値および受け入れ判定については、本書を統合仕様とする。

適用の優先順位は次のとおりとする。

1. 無効値や古い値による誤鳴動を防止する安全要求
2. 本書に記載したCloudBaseVarioの仕様
3. `vario_audio_requirements.adoc`に記載した利用者要求
4. XC Tracerの調査値および機種固有仕様

XC Tracerの設定値は設計上の参考であり、CloudBaseVarioの標準値としてそのまま採用しない。

## 3. 適用範囲

### 3.1 対象

- 上昇率から音状態を決定する規則
- リフト音、シンク音、無音および予測ブザーの音型
- 音程、周期、発音率、しきい値および応答性
- 音の有効化、無効化、異常時の無音化
- 利用者が調整できる項目
- バリオ音の受け入れ基準

### 3.2 対象外

- 気圧センサやIMUから上昇率を推定するアルゴリズム
- FreeRTOSのタスク配置やキュー構成
- PWM、LEDC、アンプ制御などの詳細なソフトウェア実装
- BLE、画面表示、飛行ログ
- 障害物警告、空域警告、電池残量音など、バリオ音以外の通知音

ただし、入力値の鮮度、出力段の音量調整、および他の通知音との識別性は、利用者体験に影響するため本書で要求を定める。

## 4. 用語と音パラメータ

| 用語 | 定義 |
| --- | --- |
| 上昇率 | 機体の鉛直速度。正値は上昇、負値は沈下を示す。単位はm/sとする。 |
| リフト音 | 上昇を知らせる断続音。 |
| シンク音 | 注意すべき強い沈下を知らせる連続音。 |
| 無音域 | 明確な上昇でも強い沈下でもない、通常は音を鳴らさない範囲。 |
| 予測ブザー | ゼロ付近または弱い上昇傾向を知らせる任意の補助音。 |
| 周波数 | 音の高さを表す値。単位はHzとする。 |
| 周期 | 1回の発音開始から次の発音開始までの時間。単位はmsとする。 |
| 鳴動時間 | 1周期内で音を出している時間。 |
| 休止時間 | 1周期内で音を止めている時間。 |
| 時間デューティ比 | `鳴動時間 / 周期 × 100`。ビープの長さを表し、音量ではない。 |
| 出力デューティ比 | PWM波形のデューティ比。時間デューティ比および知覚音量とは別の値。 |
| ヒステリシス | 開始しきい値と終了しきい値を分け、境界付近の頻繁なオン／オフを防ぐ仕組み。 |
| 古いデータ | 最後の有効な上昇率を受信してから規定時間を超えたデータ。 |

### 4.1 周期と鳴動／休止時間の関係

XC Tracerの`Tone`設定における「周期」は、鳴動時間と休止時間の合計である。

```text
周期 = 鳴動時間 + 休止時間
鳴動時間 = 周期 × 時間デューティ比 / 100
休止時間 = 周期 - 鳴動時間
```

例えば、鳴動220 ms、休止220 msの音は、周期440 ms、時間デューティ比50 %である。
要求値をXC Tracer形式の周期へ変換するときに、鳴動時間だけを周期として扱ってはならない。

## 5. 基本要求

| ID | 要求 |
| --- | --- |
| VA-REQ-001 | 上昇、強い沈下、無音域を音だけで区別できること。 |
| VA-REQ-002 | 上昇が強くなるほど、リフト音を高い音程かつ速いテンポとして知覚できること。 |
| VA-REQ-003 | 沈下が強くなるほど、シンク音を低い音程として知覚できること。 |
| VA-REQ-004 | 明確な上昇でも強い沈下でもない状態では、原則として無音であること。 |
| VA-REQ-005 | 音が無効、入力値が無効、ウォームアップ中、または入力値が古い場合は無音とすること。 |
| VA-REQ-006 | しきい値付近の入力変動で音状態が細かく切り替わらないこと。 |
| VA-REQ-007 | 上昇率の変化に対し、操縦者が不自然な遅れを感じないこと。 |
| VA-REQ-008 | 音量は、ブザー、筐体および利用環境に合わせて調整できること。 |
| VA-REQ-009 | 起動時と設定リセット後で、同じ標準音に戻ること。 |
| VA-REQ-010 | バリオ音は、警告音や操作確認音と混同しにくい音型であること。 |

## 6. 音状態

バリオ音は、`SILENT`、`LIFT`、`SINK`、`AUDIO_BUZZER`の4状態で扱う。

### 6.1 判定の優先順位

各評価周期では、次の優先順位で出力を決定する。

1. 強制無音条件
2. シンク音
3. リフト音
4. 予測ブザー
5. 無音

音の無効化、無効値、ウォームアップおよびデータ鮮度超過は、状態の最小保持時間より優先し、直ちに無音化する。
明確なリフトまたは強い沈下が成立した場合は、予測ブザーよりリフト音またはシンク音を優先する。

### 6.2 状態遷移

| 状態 | 開始条件 | 終了または遷移条件 | 出力 |
| --- | --- | --- | --- |
| `SILENT` | 初期状態、強制無音、または他の音条件が不成立 | リフト、シンク、または有効な予測ブザー条件が成立 | 無音 |
| `LIFT` | 上昇率がリフト開始しきい値を超える | 上昇率がリフト終了しきい値未満になる、シンク条件が成立、または強制無音 | 断続音 |
| `SINK` | シンク音が有効で、上昇率がシンク開始しきい値未満になる | シンク音が無効、上昇率がシンク終了しきい値を超える、または強制無音 | 連続音 |
| `AUDIO_BUZZER` | 予測ブザーが有効で、その対象範囲に入る | 明確なリフトまたはシンク、対象範囲外、機能無効、または強制無音 | 補助断続音 |

標準しきい値の比較は厳密な不等号とする。しきい値と等しい場合は新しい状態を開始または終了せず、現在の状態を維持する。

### 6.3 ヒステリシスと最小保持

- リフト開始値とリフト終了値を分ける。
- シンク開始値とシンク終了値を分ける。
- 通常の状態遷移には、標準60 msの最小保持時間を設ける。
- リフト終了時は、ビープの途中で音を切って不自然な短音にせず、原則として現在の鳴動周期の区切りで無音へ戻る。
- 強制無音条件では周期の区切りを待たない。

## 7. リフト音仕様

### 7.1 音型

リフト音は断続音とし、シンク音の連続音と容易に区別できること。

上昇率が増えるほど、次の変化を連続的に与える。

- 周波数を上げる。
- 周期を短くする。
- 鳴動時間と休止時間を短くする。
- 強い上昇でも、リフト音と分かる休止を残す。

### 7.2 標準テンポ

標準体験の目安を次に示す。値は鳴動時間と休止時間を個別に表す。

| 上昇率 | 鳴動時間 | 休止時間 | 1周期 | 時間デューティ比 | 操縦者が受け取る印象 |
| ---: | ---: | ---: | ---: | ---: | --- |
| +0.2 m/s | 約480 ms | 約480 ms | 約960 ms | 50 % | 弱い上昇。ゆっくりした断続音。 |
| +1.0 m/s | 約220 ms | 約220 ms | 約440 ms | 50 % | 実用的な上昇。明確に速い。 |
| +2.5 m/s | 約100 ms | 約100 ms | 約200 ms | 50 % | 強い上昇。素早い断続音。 |
| +5.0 m/s以上 | 約70 ms | 約70 ms | 約140 ms | 50 % | 非常に強い上昇。高密度の断続音。 |

表の点間では、音程およびテンポが急変しないよう連続的に変化させる。
+5.0 m/s以上では、標準の鳴動時間および休止時間を70 ms未満にしない。
全体のテンポは調整可能とするが、調整後も上昇が強いほど速くなる関係を維持する。

この表をCloudBaseVarioの標準テンポに対する適合基準とする。
Pico版の現行式による約414 ms（+1.0 m/s）および約285 ms（+2.5 m/s）という鳴動／休止時間は、移植互換性の参考値であり、本書の標準テンポには採用しない。

### 7.3 音程

リフト音の周波数は上昇率に対して単調非減少とする。
標準の具体的な基準周波数、増加率および上限は、PAM8904E、ブザーおよび筐体を組み合わせた実機の聴感評価で決定する。

起動時と設定リセット時で異なる基準周波数を使用してはならない。
採用値は1か所の標準設定から生成し、全経路で共有すること。

## 8. シンク音仕様

### 8.1 音型

シンク音は連続音とし、リフト音の断続音と容易に区別できること。

沈下が強くなるほど周波数を低くする。ただし、極端な沈下でも聞き取りにくい周波数まで下げない。

### 8.2 標準特性

- シンク音の時間デューティ比は100 %とする。
- 標準の最低周波数は130 Hzとする。
- シンク音の周波数は、沈下が強くなる方向に対して単調非増加とする。
- シンク音は個別に有効／無効を切り替えられること。
- シンク解除条件が成立した場合は、不要な連続音を残さず停止すること。

具体的な基準周波数および変化率は、リフト音と同様に実機の聴感評価で決定する。

## 9. 無音域仕様

通常は、リフト開始条件もシンク開始条件も成立しない範囲を無音とする。

- 無音域では、不要なビープで操縦者の注意を奪わないこと。
- 無音域からリフトまたはシンクへ移るときは、状態変化を把握できる速さで反応すること。
- 予測ブザーを有効にした場合に限り、無音域の一部で補助音を許可する。

## 10. 予測ブザー仕様

予測ブザーは任意機能とし、標準では無効とする。

有効時の標準候補は次のとおりとする。

| 項目 | 標準候補 |
| --- | ---: |
| 対象範囲 | -0.1～+0.1 m/s |
| 周波数 | 800 Hz |
| 鳴動時間 | 20 ms |
| 休止時間 | 20 ms |

予測ブザーは、通常の無音域を必ず置き換える機能ではない。
利用者が有効／無効、対象範囲、周波数、鳴動時間および休止時間を調整できることを推奨する。

## 11. 音プロファイル

### 11.1 論理モデル

調査結果を踏まえ、バリオ音の調整単位は次の4要素で表せることを推奨する。

```text
TonePoint = (上昇率, 周波数, 周期, 時間デューティ比)
```

複数の`TonePoint`を使用する場合は、次を満たすこと。

- 上昇率の昇順に定義する。
- 隣接点の上昇率を同じ値にしない。
- 点間の周波数、周期および時間デューティ比を連続的に補間する。
- 設定範囲外では、端点値の保持または安全な上限／下限クランプを行う。
- 不正な並び、範囲外の周波数、ゼロ以下の周期を拒否する。

内部実装は、制御点の補間、数式、または両者の組み合わせのいずれでもよい。
ただし、利用者から見た音が本書の状態、単調性、標準テンポおよび安全要求を満たすこと。

### 11.2 XC Tracer調査値の扱い

XC Tracer Mini VおよびMaxx IIIは、12個の`Tone`点で上昇率、周波数、周期、時間デューティ比を指定する。
この方式から「上昇率ごとに音程、テンポ、ビープ長を独立して設計する」という考え方を採用する。

一方、次のXC Tracer固有条件はCloudBaseVarioの必須仕様とはしない。

- 制御点を必ず12個にすること
- 最初を-10 m/s、最後を+10 m/sにすること
- 不足点をEEPROM値で補うこと
- XC Tracerの標準しきい値や音量段階をそのまま使用すること

## 12. 標準設定

| 項目 | CloudBaseVario標準値 | 備考 |
| --- | ---: | --- |
| バリオ音 | 有効 | 有効な上昇率が得られた後に動作する。 |
| 音状態の評価周期 | 10 ms以下 | 変化に追従する目標値。 |
| 古いデータの無音化 | 500 ms | 超過時は直ちに無音化する。 |
| リフト開始 | `> +0.1 m/s` | 等しい場合は開始しない。 |
| リフト終了 | `< +0.05 m/s` | 等しい場合は終了しない。 |
| シンク開始 | `< -1.0 m/s` | 等しい場合は開始しない。 |
| シンク終了 | `> -0.8 m/s` | 等しい場合は終了しない。 |
| 状態の最小保持 | 60 ms | 強制無音には適用しない。 |
| リフトの最短鳴動時間 | 70 ms | 標準テンポ。 |
| リフトの最短休止時間 | 70 ms | 断続音として識別可能にする。 |
| リフトの時間デューティ比 | 50 % | 標準テンポ点。 |
| シンク音 | 有効 | 個別に無効化可能。 |
| シンク音の最低周波数 | 130 Hz | 聞き取り可能な下限。 |
| 予測ブザー | 無効 | 静かな無音域を優先する。 |
| 出力PWMデューティ比 | 50 % | 波形の基準値であり、時間デューティ比とは別。 |
| 全体テンポ倍率 | 1.0 | 利用者調整可能。 |

音量の標準は「中程度」を目標とする。
数値上の50 %、アンプの1倍／2倍／3倍、および知覚音量は同義ではないため、PAM8904E、ブザー、供給電圧、取り付け方法および筐体を含む実機評価で標準増幅モードを決定する。

## 13. 調整可能項目

利用者または製品調整者は、少なくとも次の項目を変更できること。

| 分類 | 調整項目 |
| --- | --- |
| 全体 | バリオ音の有効／無効、音量または増幅モード、出力デューティ比 |
| リフト | 開始／終了しきい値、基準周波数、周波数変化率または音程プロファイル、テンポ、最短鳴動／休止時間 |
| シンク | 有効／無効、開始／終了しきい値、基準周波数、周波数変化率、最低周波数 |
| 予測ブザー | 有効／無効、対象範囲、周波数、鳴動時間、休止時間 |
| 安定性 | 状態の最小保持時間、必要に応じて上昇率のダンピング |

不正値を設定した場合は、安全な範囲へ黙って変形するのではなく、原則として設定を拒否して元の値を維持する。
設定リセット後は、本書で定めた標準値へ戻ること。

## 14. 応答性、ダンピングおよび飛行判定

### 14.1 応答性

- 音状態は10 ms以下の周期で評価することを目標とする。
- 新しい有効値を受信した場合は、古い未処理値より最新値を優先する。
- 音の安定化のために過大な遅延を加えない。

### 14.2 ダンピング

XC Tracerでは、ダンピング係数により音の元となる上昇率の応答を調整できる。
CloudBaseVarioでも調整機能を設けてよいが、ダンピングは音程や周期を直接変更する値ではなく、音状態へ入力する上昇率の平滑化として扱う。

ダンピングを変更しても、無効値および古い値の検出を遅らせてはならない。

### 14.3 飛行中のみ鳴らす機能

信頼できる飛行判定を利用できる構成では、離陸前の誤鳴動を防ぐ「飛行中のみ鳴らす」機能を任意で提供してよい。
この機能を有効にした場合、非飛行状態は強制無音条件として扱う。

水平速度など特定のセンサを搭載しない構成でも基本のバリオ音が動作すること。
XC Tracer Mini Vの「水平速度4 m/s以上を1～2秒検出」という条件は参考値であり、CloudBaseVarioの必須条件とはしない。

### 14.4 TEK補正

TEK（Total Energy Compensation）は、機体速度と高度の変換による一時的な上昇表示を補正する入力側の機能であり、音プロファイルそのものではない。
TEKを採用する場合も、本書の音状態と音型は、補正後の有効な上昇率に対して同様に適用する。

## 15. 安全性と快適性

| ID | 要求 |
| --- | --- |
| VA-SAFE-001 | 音無効時、入力無効時、ウォームアップ中、または500 msを超えて更新がない場合は音を出さないこと。 |
| VA-SAFE-002 | 強制無音時は、出力段を確実に無音状態へ設定すること。 |
| VA-SAFE-003 | 起動直後に未確定値でリフト音またはシンク音を出さないこと。 |
| VA-SAFE-004 | リフト、シンク、予測ブザーおよび警告音を飛行中に混同しにくいこと。 |
| VA-SAFE-005 | しきい値付近の短時間ノイズで状態が過剰に切り替わらないこと。 |
| VA-SAFE-006 | シンク音は警告性を持つ一方、長時間聞いても不快すぎない音域に収めること。 |
| VA-SAFE-007 | 設定値が破損または範囲外の場合は、安全な既定値を使用するか無音とすること。 |

バリオ音は操縦を補助する情報であり、安全な飛行判断を保証するものではない。

## 16. 受け入れ基準

### 16.1 状態としきい値

| ID | 確認内容 |
| --- | --- |
| VA-AC-001 | 無音状態から上昇率を+0.1 m/sより大きくすると、リフト音を開始する。 |
| VA-AC-002 | +0.1 m/sちょうどでは、無音状態からリフト音を開始しない。 |
| VA-AC-003 | リフト中に+0.05 m/s未満へ下げると、自然な周期境界で無音へ戻る。 |
| VA-AC-004 | リフト中に+0.05 m/sちょうどとなった場合は、終了判定を行わない。 |
| VA-AC-005 | 上昇率を-1.0 m/s未満にすると、連続したシンク音を開始する。 |
| VA-AC-006 | -1.0 m/sちょうどでは、無音状態からシンク音を開始しない。 |
| VA-AC-007 | シンク中に-0.8 m/sより大きく戻すと、シンク音を停止する。 |
| VA-AC-008 | シンク中に-0.8 m/sちょうどとなった場合は、終了判定を行わない。 |

## 17. 調査結果からの採用判断

| XC Tracerで確認した設計要素 | CloudBaseVarioでの扱い |
| --- | --- |
| 上昇音と沈下音に別々の開始／終了しきい値を持つ | 採用。CloudBaseVario固有の標準値を使用する。 |
| 上昇率ごとに周波数、周期、時間デューティ比を設定する | 設計概念を採用。内部表現は固定しない。 |
| 12個のTone点を必須とする | 不採用。XC Tracer互換設定を扱う場合だけ使用してよい。 |
| 強い上昇ほど高音、短周期、高い時間デューティ比とする | 高音化と短周期化を採用。標準の時間デューティ比は50 %とし、休止を維持する。 |
| 強い沈下を低い連続音で示す | 採用。最低周波数を設ける。 |
| Tone Simulatorで設定を試聴する | 開発・調整ツールの考え方として推奨する。 |
| ダンピングを調整する | 入力上昇率の平滑化として任意採用する。 |
| 飛行中のみ鳴らす | 飛行判定を利用できる構成で任意採用する。 |
| TEK補正 | 将来拡張。音生成ではなく入力上昇率の補正として扱う。 |
| Mini V／Maxx III固有の音量段階 | 直接採用しない。CloudBaseVarioの出力回路と筐体で決定する。 |

## 18. XC Tracer標準トーンの参考値

以下は音プロファイル設計の参考であり、CloudBaseVarioの標準値ではない。

```text
Tone=-10.00,200,100,100
Tone=-3.00,280,100,100
Tone=-0.51,300,500,100
Tone=-0.50,200,800,5
Tone=0.09,400,600,10
Tone=0.10,400,600,50
Tone=1.16,550,552,52
Tone=2.67,763,483,55
Tone=4.24,985,412,58
Tone=6.00,1234,332,62
Tone=8.00,1517,241,66
Tone=10.00,1800,150,70
```

各行は`Tone=<上昇率[m/s]>,<周波数[Hz]>,<周期[ms]>,<時間デューティ比[%]>`を表す。

この参考値から、次の傾向を確認できる。

- 強い沈下は低い連続音とする。
- ゼロ付近では短い補助音または無音を構成できる。
- 上昇開始時にビープを明確にする。
- 強い上昇ほど高音かつ短周期にする。

## 19. 未決事項

次の項目は、実機での聴感評価後に本書へ確定値を反映する。

- リフト音の標準基準周波数、増加率および上限
- シンク音の標準基準周波数および変化率
- PAM8904Eの標準増幅モード
- 屋外利用を含む音量段階と設定方法
- 標準テンポ表に対する許容差
- 予測ブザーを製品設定として公開するか、開発者向け設定に留めるか
- 飛行判定およびTEK補正を初期製品範囲へ含めるか

これらを確定するまで、起動値とリセット値を別々に定義してはならない。
