# CloudBaseVario バリオ音仕様書

| 項目 | 内容 |
| --- | --- |
| 文書名 | バリオ音仕様書 |
| 対象 | CloudBaseVario |
| 版 | 1.1 |
| 更新日 | 2026-07-29 |
| 状態 | 統合仕様 |

## 1. 目的

本書は、CloudBaseVarioが操縦者へ提示するバリオ音の要件を定義する。
操縦者が画面を見なくても、上昇、強い沈下、通常の無音域を直感的に区別できることを目的とする。

本書の「要求」は必須、「推奨」は可能な限り満たす事項、「任意」は利用者または製品構成により選択できる事項を表す。

## 2. 文書の位置付け

バリオ音の動作および受け入れ判定については、本書をCloudBaseVarioの統合仕様とする。
設定可能な特性は具体値で固定せず、対応するパラメータ名で示す。既定値、設定可能範囲および型の正本は、ファームウェアの単一パラメータ定義とする。

適用の優先順位は次のとおりとする。

1. 無効値や古い値による誤鳴動を防止する安全要求
2. 本書に記載したCloudBaseVarioの要件
3. ファームウェアの単一パラメータ定義

## 3. 適用範囲

### 3.1 対象

- 上昇率から音状態を決定する規則
- リフト音、シンク音、無音および予測ブザーの音型
- 音程、テンポ、しきい値および応答性
- 音の有効化、無効化および異常時の無音化
- 利用者が調整できる項目
- バリオ音の受け入れ基準

### 3.2 対象外

- 気圧センサやIMUから上昇率を推定するアルゴリズム
- FreeRTOSのタスク配置やキュー構成
- PWM、LEDC、アンプ制御などの詳細なソフトウェア実装
- BLE、画面表示および飛行ログ
- 起動音、終了音、障害物警告、空域警告、電池残量音など、バリオ音以外の通知音

ただし、入力値の鮮度、出力段の音量調整、および他の通知音との識別性は、利用者体験に影響するため本書で要求を定める。

## 4. 用語

| 用語 | 定義 |
| --- | --- |
| 上昇率 | 機体の鉛直速度。正値は上昇、負値は沈下を示す。 |
| リフト音 | 上昇を知らせる断続音。 |
| シンク音 | 注意すべき強い沈下を知らせる連続音。 |
| 無音域 | 明確な上昇でも強い沈下でもなく、通常は音を鳴らさない範囲。 |
| 予測ブザー | ゼロ付近または弱い上昇傾向を知らせる任意の補助音。 |
| 鳴動時間 | 断続音の一周期内で音を出している時間。 |
| 休止時間 | 断続音の一周期内で音を止めている時間。 |
| 出力デューティ比 | PWM波形のデューティ比。断続音の鳴動時間比率および知覚音量とは別の値。 |
| ヒステリシス | 開始しきい値と終了しきい値を分け、境界付近の頻繁な状態切替を防ぐ仕組み。 |
| 古いデータ | 最後の有効な上昇率を受信してから `audio_stale_ms` を超えたデータ。 |
| 強制無音 | 通常の状態保持や断続音の位相より優先して出力を停止する状態。 |

## 5. 基本要求

| ID | 要求 |
| --- | --- |
| VA-REQ-001 | 上昇、強い沈下、無音域を音だけで区別できること。 |
| VA-REQ-002 | 上昇が強くなるほど、リフト音を高い音程かつ速いテンポとして知覚できること。 |
| VA-REQ-003 | 沈下が強くなるほど、シンク音を低い音程として知覚できること。 |
| VA-REQ-004 | 明確な上昇でも強い沈下でもない状態では、原則として無音であること。 |
| VA-REQ-005 | 音が無効、入力値が無効、ウォームアップ中、または入力値が古い場合は無音とすること。 |
| VA-REQ-006 | しきい値付近の入力変動で音状態が細かく切り替わらないこと。 |
| VA-REQ-007 | 上昇率の変化に対し、操縦者が不自然な遅れを感じないこと。 |
| VA-REQ-008 | 出力特性は、ブザー、筐体および利用環境に合わせて調整できること。 |
| VA-REQ-009 | 起動時と設定リセット後で、同じパラメータ定義に基づく音へ戻ること。 |
| VA-REQ-010 | バリオ音は、警告音や操作確認音と混同しにくい音型であること。 |

## 6. パラメータ

設定可能なバリオ音特性は、次のパラメータで表す。

| 分類 | パラメータ | 役割 |
| --- | --- | --- |
| 全体 | `audio_enabled` | バリオ音全体の有効／無効 |
| 全体 | `audio_state_hold_ms` | 通常の音状態を維持する最小時間 |
| 全体 | `audio_stale_ms` | 入力を古いデータと判定する時間 |
| 出力 | `audio_duty_percent` | PWM出力デューティ比 |
| 出力 | `audio_amp_mode` | PAM8904Eの増幅モード |
| リフト判定 | `lift_start_mps` | `SILENT`から`LIFT`へ入る開始しきい値 |
| リフト判定 | `lift_end_mps` | `LIFT`から抜ける終了しきい値 |
| リフト音程 | `lift_freq_base_hz` | リフト音の基準周波数 |
| リフト音程 | `lift_freq_rate_hz_per_mps` | 上昇率に対する周波数変化率 |
| リフト音程 | `lift_freq_max_hz` | リフト音の上限周波数 |
| リフトテンポ | `lift_time_ms_at_0p2` | 最弱側のリフトテンポ制御点 |
| リフトテンポ | `lift_time_ms_at_1p0` | 弱中間側のリフトテンポ制御点 |
| リフトテンポ | `lift_time_ms_at_2p5` | 強中間側のリフトテンポ制御点 |
| リフトテンポ | `lift_time_ms_at_5p0` | 最強側のリフトテンポ制御点 |
| シンク判定 | `sink_enabled` | シンク音の有効／無効 |
| シンク判定 | `sink_start_mps` | `SILENT`から`SINK`へ入る開始しきい値 |
| シンク判定 | `sink_end_mps` | `SINK`から抜ける終了しきい値 |
| シンク音程 | `sink_freq_start_hz` | シンク開始側の基準周波数 |
| シンク音程 | `sink_freq_rate_hz_per_mps` | 沈下の強さに対する周波数変化率 |
| シンク音程 | `sink_freq_min_hz` | シンク音の下限周波数 |
| 予測ブザー | `predictive_buzzer_enabled` | 予測ブザーの有効／無効 |
| 予測ブザー | `predictive_min_mps` | 予測ブザー対象範囲の下限 |
| 予測ブザー | `predictive_max_mps` | 予測ブザー対象範囲の上限 |
| 予測ブザー | `predictive_freq_hz` | 予測ブザーの周波数 |
| 予測ブザー | `predictive_on_ms` | 予測ブザーの鳴動時間 |
| 予測ブザー | `predictive_off_ms` | 予測ブザーの休止時間 |

パラメータの既定値、型および設定可能範囲を文書内へ重複定義してはならない。

## 7. 音状態

バリオ音は、`SILENT`、`LIFT`、`SINK`、`AUDIO_BUZZER`の状態で扱う。

### 7.1 判定の優先順位

各評価周期では、次の優先順位で出力を決定する。

1. 強制無音条件
2. 現在の音状態に対する終了判定
3. リフト開始判定
4. シンク開始判定
5. 予測ブザー開始判定
6. 無音

強制無音条件は `audio_state_hold_ms` および断続音の位相より優先し、直ちに無音化する。

### 7.2 状態遷移

| 状態 | 開始条件 | 終了または遷移条件 | 出力 |
| --- | --- | --- | --- |
| `SILENT` | 初期状態、強制無音、または他の音条件が不成立 | 上昇率が `lift_start_mps` を超える、`sink_enabled` が有効かつ上昇率が `sink_start_mps` 未満になる、または有効な予測ブザー条件が成立 | 無音 |
| `LIFT` | 上昇率が `lift_start_mps` を超える | 上昇率が `lift_end_mps` 未満になる、または強制無音 | 断続音 |
| `SINK` | `sink_enabled` が有効で、上昇率が `sink_start_mps` 未満になる | `sink_enabled` が無効になる、上昇率が `sink_end_mps` を超える、または強制無音 | 連続音 |
| `AUDIO_BUZZER` | `predictive_buzzer_enabled` が有効で、上昇率が `predictive_min_mps` 以上かつ `predictive_max_mps` 以下になる | 機能無効、対象範囲外、または強制無音 | 補助断続音 |

開始および終了しきい値の比較は表に記載した不等号を使用する。しきい値と等しい場合は、表で等号を含む予測ブザー条件を除き、新しい状態を開始または終了せず現在の状態を維持する。

### 7.3 ヒステリシスと状態保持

- リフト判定には `lift_start_mps` と `lift_end_mps` を使用する。
- シンク判定には `sink_start_mps` と `sink_end_mps` を使用する。
- 通常の状態遷移には `audio_state_hold_ms` を適用する。
- リフト終了時は、原則として現在の鳴動区間の終了まで音を維持し、不自然な短音を発生させない。
- 強制無音条件では状態保持や鳴動区間の終了を待たない。

## 8. リフト音

### 8.1 音型

リフト音は断続音とし、シンク音の連続音と容易に区別できること。
上昇率が増えるほど、次の変化を連続的に与える。

- 周波数を下げない。
- 鳴動時間と休止時間を長くしない。
- 強い上昇でも、リフト音と識別できる休止を残す。

### 8.2 音程

リフト音の周波数は、`lift_freq_base_hz` と `lift_freq_rate_hz_per_mps` から上昇率に応じて求め、`lift_freq_max_hz` を超えないこと。
上昇率が強くなる方向に対して周波数を単調非減少とする。

### 8.3 テンポ

リフト音の鳴動時間と休止時間には、次の制御点を使用する。

- `lift_time_ms_at_0p2`
- `lift_time_ms_at_1p0`
- `lift_time_ms_at_2p5`
- `lift_time_ms_at_5p0`

制御点間は連続的に補間し、設定範囲外では端の制御点を保持する。
各制御点は、上昇率が強くなる方向に対して同じか短くなる関係を満たすこと。

## 9. シンク音

シンク音は連続音とし、リフト音の断続音と容易に区別できること。

- `sink_enabled` が無効な場合はシンク音を出さない。
- シンク開始側の周波数は `sink_freq_start_hz` で定める。
- 沈下が強くなるほど、`sink_freq_rate_hz_per_mps` に従って周波数を低くする。
- 周波数は `sink_freq_min_hz` を下回らない。
- シンク解除条件が成立した場合は、不要な連続音を残さず停止する。

## 10. 無音域

通常は、リフト開始条件、シンク開始条件および有効な予測ブザー条件のいずれも成立しない範囲を無音とする。

- 無音域では不要なビープで操縦者の注意を奪わないこと。
- 無音域からリフトまたはシンクへ移るときは、状態変化を把握できる速さで反応すること。
- 予測ブザーを有効にした場合に限り、無音域の一部で補助音を許可する。

## 11. 予測ブザー

予測ブザーは任意機能とし、`predictive_buzzer_enabled` で有効化する。

- 対象範囲は `predictive_min_mps` と `predictive_max_mps` で定める。
- 周波数は `predictive_freq_hz` で定める。
- 鳴動時間は `predictive_on_ms`、休止時間は `predictive_off_ms` で定める。
- 通常の無音域を常に置き換える機能としてはならない。

## 12. 出力特性

- PWM出力デューティ比は `audio_duty_percent` で定める。
- PAM8904Eの増幅モードは `audio_amp_mode` で定める。
- 鳴動中だけ選択した増幅モードを有効にする。
- 無音時は音声入力とアンプ制御信号を無効状態にする。
- 数値上のPWMデューティ比、増幅モードおよび知覚音量を同義として扱わない。
- ブザー、供給電圧、取り付け方法および筐体を含む実機評価で、音圧、歪みおよび聞き分けやすさを確認する。

## 13. 設定検証と永続化

設定変更時は少なくとも次の相互関係を検証する。

- `sink_start_mps <= sink_end_mps < lift_end_mps <= lift_start_mps`
- `lift_freq_base_hz <= lift_freq_max_hz`
- `sink_freq_min_hz <= sink_freq_start_hz`
- `predictive_min_mps <= predictive_max_mps`
- リフトテンポ制御点は、上昇率が強くなる方向に対して同じか短い

不正値を安全な範囲へ黙って変形してはならない。設定を拒否し、変更前の値を維持すること。
設定リセット後は、ファームウェアの単一パラメータ定義にある既定値へ戻ること。
起動値とリセット値を別々に定義してはならない。

## 14. 応答性と入力

- 音状態は、上昇率の変化を操縦者が不自然な遅れとして感じない周期で評価すること。
- 新しい有効値を受信した場合は、古い未処理値より最新値を優先すること。
- 音の安定化のために過大な遅延を加えないこと。
- 入力側で平滑化を行う場合も、無効値および古い値の検出を遅らせてはならない。
- TEKなどの入力補正を採用する場合、本書の状態判定と音型は補正後の有効な上昇率へ適用すること。
- 特定の追加センサや飛行判定機能を利用できない構成でも、基本のバリオ音が動作すること。

## 15. 安全性と快適性

| ID | 要求 |
| --- | --- |
| VA-SAFE-001 | `audio_enabled` が無効、入力無効、入力が非有限、タイムスタンプが不正、ウォームアップ中、または入力の経過時間が `audio_stale_ms` を超えた場合は音を出さないこと。 |
| VA-SAFE-002 | 強制無音時は、出力段を確実に無音状態へ設定すること。 |
| VA-SAFE-003 | 起動直後に未確定値でリフト音またはシンク音を出さないこと。 |
| VA-SAFE-004 | リフト、シンク、予測ブザーおよび通知音を飛行中に混同しにくいこと。 |
| VA-SAFE-005 | しきい値付近の短時間ノイズで状態が過剰に切り替わらないこと。 |
| VA-SAFE-006 | シンク音は警告性を持つ一方、長時間聞いても不快すぎない音域に収めること。 |
| VA-SAFE-007 | 設定値が破損または範囲外の場合は、安全な既定値を使用するか無音とすること。 |

バリオ音は操縦を補助する情報であり、安全な飛行判断を保証するものではない。

## 16. 受け入れ基準

### 16.1 状態としきい値

| ID | 確認内容 |
| --- | --- |
| VA-AC-001 | `SILENT`で上昇率を `lift_start_mps` より大きくすると、`LIFT`を開始する。 |
| VA-AC-002 | `SILENT`で上昇率を `lift_start_mps` と等しくしても、`LIFT`を開始しない。 |
| VA-AC-003 | `LIFT`中に上昇率を `lift_end_mps` 未満へ下げると、自然な鳴動区間の境界で`SILENT`へ戻る。 |
| VA-AC-004 | `LIFT`中に上昇率を `lift_end_mps` と等しくしても、終了判定を行わない。 |
| VA-AC-005 | `sink_enabled` を有効にし、上昇率を `sink_start_mps` 未満にすると、`SINK`を開始する。 |
| VA-AC-006 | `SILENT`で上昇率を `sink_start_mps` と等しくしても、`SINK`を開始しない。 |
| VA-AC-007 | `SINK`中に上昇率を `sink_end_mps` より大きくすると、`SINK`を停止する。 |
| VA-AC-008 | `SINK`中に上昇率を `sink_end_mps` と等しくしても、終了判定を行わない。 |

### 16.2 音型

| ID | 確認内容 |
| --- | --- |
| VA-AC-009 | リフトテンポ制御点を弱い上昇側から強い上昇側へ評価したとき、音程が低下せずテンポが遅くならない。 |
| VA-AC-010 | リフトテンポ制御点間で、鳴動時間と休止時間が不連続に変化しない。 |
| VA-AC-011 | リフトテンポ制御点の範囲外で、対応する端の設定値を保持する。 |
| VA-AC-012 | シンク音が連続音として聞こえ、リフト音と区別できる。 |
| VA-AC-013 | 沈下を強めたとき、シンク音の音程が高くならない。 |
| VA-AC-014 | 強い沈下でも、シンク音が `sink_freq_min_hz` を下回らない。 |

### 16.3 無音と異常

| ID | 確認内容 |
| --- | --- |
| VA-AC-015 | `audio_enabled` を無効にすると、上昇率にかかわらず無音になる。 |
| VA-AC-016 | 入力値を無効または非有限にすると、`audio_state_hold_ms` や鳴動区間を待たず無音になる。 |
| VA-AC-017 | 有効値の更新を停止し、入力の経過時間が `audio_stale_ms` を超えると無音になる。 |
| VA-AC-018 | しきい値の内外を短時間に変動させても、状態が過剰に切り替わらない。 |
| VA-AC-019 | 設定をリセットすると、起動時と同じ音程、テンポおよびしきい値へ戻る。 |

### 16.4 任意機能

| ID | 確認内容 |
| --- | --- |
| VA-AC-020 | `predictive_buzzer_enabled` を有効にすると、`predictive_min_mps` から `predictive_max_mps` までの範囲で補助音が鳴る。 |
| VA-AC-021 | `sink_enabled` を無効にすると、上昇率が `sink_start_mps` 未満でもシンク音が鳴らない。再度有効にすると通常動作へ戻る。 |

## 17. 未決事項

次の項目は、CloudBaseVario実機での聴感評価後に単一パラメータ定義へ反映する。

- リフト音の基準周波数、変化率および上限
- シンク音の基準周波数、変化率および下限
- PAM8904Eの増幅モード
- 屋外利用を含む音量と設定方法
- リフトテンポ制御点の設定
- 予測ブザーを製品設定として公開するか、開発者向け設定に留めるか

聴感評価の結果を本書へ具体値として重複記載せず、対応するパラメータ名と要求上の関係を維持する。
